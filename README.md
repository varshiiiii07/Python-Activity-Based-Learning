Project Overview
This activity contains Python case studies (81--90) that demonstrate how
programming concepts can be applied to practical campus, education,
business, banking, food-supply, and environmental problems.
Case Studies Included
1. Case Study 81 -- Campus Event Seating and Entry Validation
   Assigns seats, validates registered ticket IDs, detects invalid and
   duplicate entries, and calculates available seating capacity.
2. Case Study 82 -- Multi-Criteria Internship Candidate Ranking
   Checks candidate eligibility, calculates weighted scores, ranks
   qualified candidates, and applies tie-breaking rules.
3. Case Study 83 -- Food Supply Chain Stock Reconciliation
   Compares expected and actual stock, identifies shortages or excess
   stock, and calculates replenishment requirements.
4. Case Study 84 -- Environmental Monitoring Data Analyzer
   Analyzes readings from multiple locations using averages, minimums,
   maximums, and threshold-based classifications.
5. Smart Classroom Timetable Allocation
   Allocates courses to classrooms and time periods while checking room
   capacity and timetable clashes.
   Note: The source presentation labels this section as Case 84,
   although the case-study list identifies it as item 85.
6. Case Study 86 -- Multi-Stage ATM Transaction Audit
   Processes deposits, withdrawals, and transfers, validates
   transactions, maintains balances, and flags repeated patterns for
   review.
7. Case Study 87 -- Examination Question Difficulty and Performance
   Analysis
   Compares student answers with an answer key, calculates
   question-wise success rates, and identifies frequently missed
   questions.
8. Case Study 88 -- Multi-Branch Retail Inventory Transfer
   Calculates branch-level stock surpluses and shortages and recommends
   transfers while respecting transfer limits.
9. Case Study 89 -- University Hostel Room Allocation
   Assigns student groups to eligible rooms, checks capacity, detects
   duplicate student IDs, and reports unallocated students.
10. Case Study 90 -- Integrated Campus Energy and Water Audit
    Analyzes electricity and water use, estimates costs, identifies
    excessive consumption, and ranks buildings by a resource-consumption
    score.

How to Run
1. Install Python 3.
2. Save the required case-study program in a file with a .py
   extension.
3. Open a terminal or command prompt in the file's folder.
4. Run:
   python filename.py
   Replace filename.py with the actual Python file name.
